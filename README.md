# Mini Hospital Emergency Management System

A console-based emergency hospital management system built in Java using custom core Data Structures and Algorithms.

## Data Structures Implemented

1. **Binary Search Tree (BST) — Patient Records**
   - Stores patient registry with `Patient ID` as the primary key.
   - Operations: Insert, Search, Delete (0, 1, and 2-child cases), and In-Order Traversal for sorted listings.

2. **FIFO Queue — Emergency Patient Queue**
   - Manages emergency triage arrivals following First-In, First-Out order.
   - Operations: Enqueue, Dequeue, Display Waiting Line, and Empty Queue handling.

3. **LIFO Stack — Treatment History**
   - Tracks completed treatments following Last-In, First-Out order.
   - Operations: Push completed treatments, Pop (undo recent treatment), and Display history.

4. **Singly Linked List — Patient Visit History**
   - Maintains individual historical medical visits for each registered patient.
   - Operations: Add visit, Remove visit by ID, Search visit, and Display visit log.
